# 小卡認天下的聲音

所有聲音都是用程式合成的（numpy、scipy）：沒有錄音、沒有下載別人的素材，兩首曲子都是為這個 APP 新寫的。

- 合成用的小工具（鐘聲、木琴、拇指琴、接成循環、動物聲音的共鳴方法……）是從動物小餐廳和字母寵物的 `design/sounds/make_sounds.py` 複製過來的。
- 動物叫聲、警笛、喇叭、飛機、直升機、垃圾車的音樂、挖土機，是從畫畫小鎮的 `docs/design/sounds/make_sounds.py` 改的：改得更輕柔、更可愛。
- 新做的有：鋼片琴（celesta）、溫暖的鈴聲，以及其他的聲音。

給 2 歲起的小朋友，所以全部都是**安靜、柔和、溫暖**的：沒有刺耳或突然的聲音；動物是可愛的卡通聲音，不是嚇人的真實叫聲（獅子是友善的「吼～」）。

## 怎麼產生

```
pip install numpy scipy                                     # 只要第一次
python3 design/sounds/make_sounds.py                        # 寫到 app/assets/sounds/*.wav
python3 design/sounds/make_sounds.py preview 試聽.m4a        # 再做一個試聽檔（要 ffmpeg）
```

跑完會印出每個檔案的長度、大小、最大音量、聽起來多大聲、有沒有破音，還有背景音樂接頭的檢查。
- 亂數都用固定的種子，每次跑出來的檔案都一模一樣。
- 程式會檢查：`design/cards.json` 裡動物和交通工具的每一張卡，還有時鐘、電話、門，都有自己的聲音。
- 全部加起來超過 4,000,000 bytes 就會停下來報錯。
- 試聽檔是每首背景音樂的前 8 秒，接著每個音效照順序播一次，中間停一下，會印出每一段從第幾秒開始。

## 格式
- 全部是 WAV、單聲道、16 位元。
- 背景音樂 16,000 Hz；其他聲音 22,050 Hz。
- 背景音樂都是整數小節，可以無縫循環：曲子結尾還在響的聲音接回開頭，聽不出接縫。
- 其他聲音兩頭都有淡入淡出，第一個和最後一個點都是 0，不會「啪」一聲。
- **音量一樣大**：程式量每個聲音「從手機喇叭聽起來」有多大聲。
  - 怎麼量：用耳朵比較敏感的頻率（A 加權）、不算手機放不出來的低音，大約 0.2 秒一段（耳朵大約這樣把聲音加起來）。
  - 再把每個聲音調到一樣大聲：該輕一點的就小幾 dB。例如按鈕、翻卡、「再找找」、小鳥、老鼠、腳踏車鈴、警笛、電話，都放得比較輕。
  - 最大音量不超過 0.72。
  - 敲門、時鐘、長頸鹿、直升機是很短的一下一下，最大音量先到頂，所以比別的輕 1～4 dB。
  - 和動物小餐廳的音效差不多大聲。
- 背景音樂聽起來比音效輕（約 −28.7 dB，音效約 −21 dB），和動物小餐廳的背景音樂一樣，放在念名字和音效下面。
- 手機小喇叭放不出很低的聲音。所以牛、熊、烏龜、船、卡車、挖土機、火箭這些低低的聲音，都加了一點它自己比較高的泛音（也就是聲音裡比較高的那些成分），手機上才聽得到。
- 全部 53 個檔，加起來約 3.3 MB（3,259,314 bytes），在 4 MB 以內。

## 背景音樂

| 檔案 | 用在哪裡 | 長度 | 聽起來 |
|---|---|---|---|
| `music_play` | 玩卡片 | 18.6 秒 | F 大調，輕輕的、亮亮的。拇指琴（卡林巴）唱旋律，後半段鋼片琴高一個八度跟著唱；柔和的木琴走和弦、低音撥弦，沙鈴和木頭聲很輕地打拍子。每半首結尾有一串鋼片琴，最後往下帶回開頭 |
| `music_rest` | 休息一下 | 18.0 秒 | G 大調、三拍子的慢搖籃曲。音樂盒唱旋律，軟軟的鋼琴上下輕輕搖，低音和溫暖的長音托著 |

## 按鈕和畫面的聲音

| 檔案 | 什麼時候 | 聽起來 |
|---|---|---|
| `flip` | 翻卡片 | 紙片翻過去的輕輕「咻」，再小小「啪」一下落下 |
| `tap` | 按按鈕 | 小小軟軟的木頭「叩」 |
| `right` | 找對了 | 溫暖開心的「叮叮叮－噹」：木琴和拇指琴往上跑，落在拇指琴、豎琴和弦和小鈴聲上 |
| `try` | 點錯了、再找找 | 很輕、很友善的「嗯－嗯？」：兩個圓圓的音往上，第二個尾巴微微上揚，像在問問題；不像答錯的警告聲 |
| `next` | 換下一張 | 輕輕滑過去的「咻～」，裡面有一個小小往上滑的音 |
| `switch` | 切換真實版／卡通版 | 很小的亮晶晶，三個快快的小鈴聲 |
| `star` | 得到星星 | 鐵琴往上跑的閃閃聲 |
| `rest` | 休息時間到了 | 一聲柔和溫暖的鐘聲，上面再一聲輕輕的，慢慢地響完（1.5 秒） |

### 家裡的東西（只有會發出聲音的）

| 檔案 | 卡片 | 聽起來 |
|---|---|---|
| `say_clock` | 時鐘 | 「滴答、滴答」 |
| `say_phone` | 電話 | 輕輕的「鈴鈴鈴鈴、鈴鈴鈴鈴」 |
| `say_door` | 門 | 敲木門「叩叩」 |

動物的聲音和三個兄弟 APP 一樣，是這樣做的：
- 用一個嗡嗡聲（像聲帶），通過幾個共鳴（像嘴巴的形狀），做出「哞」「咩」「喵」這些聲音。
- 喇叭、警笛、引擎和風聲，用單純的音和沙沙的雜音合成。
